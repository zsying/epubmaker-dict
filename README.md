# epubmaker-dict

EpubMaker（https://github.com/zsying/EpubMaker）内置的在线下载词库源。

`ecdict-mini.csv` — ECDICT 格式精简词库（约 10 万高频词 + 5 万词形还原行，11.6 MB）：
- 释义取自 [mahavivo/open-ecdict](https://github.com/mahavivo/open-ecdict)（数据源头为 skywind3000/ECDICT）
- 词频（BNC）与词形还原（exchange 列）来自 [skywind3000/ECDICT](https://github.com/skywind3000/ECDICT) 的 lemma.en.txt

通过 jsDelivr 分发：`https://cdn.jsdelivr.net/gh/zsying/epubmaker-dict@main/ecdict-mini.csv`
